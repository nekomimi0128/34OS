34OS

It's very hyper ultra super mega light-weight OS — an ultra-lightweight Linux distribution based on Ubuntu 24.04, built to run comfortably on old, low-spec PCs.

WHAT IS 34OS?

34OS is a personal Linux distribution that aims to be lighter than Puppy Linux while keeping the everyday command-line feel of Ubuntu — GNU coreutils, bash and apt. The live ISO is about 750 MB and boots from USB. The weight is saved not by removing commands, but by trimming locales, documentation and firmware, and compressing the file system with SquashFS. It has been tested on real hardware as old as a first-generation Core i5 laptop (dynabook).

  • Base: Ubuntu 24.04 LTS (minimal debootstrap)
  • Shell: bash / Package management: apt
  • GUI: Xorg + Fluxbox (standard session), Firefox (official Mozilla .deb — no snap), PCManFM, sakura terminal
  • Installer: install34 installs from the live session to HDD/SSD — full wipe or dual boot, UEFI and BIOS
  • Boot media: Rufus (DD mode) or Ventoy. Secure Boot is supported (signed shim and GRUB), so it can stay enabled
  • Live session login: user user / password live

CUSTOM COMMANDS

goguiStart the GUI (Fluxbox, or Astro if the ~/.34os-astro flag file exists)
gocliStop the GUI and return to the CLI
browserOpen the browser (Firefox)
imgDisplay an image (feh)
playPlay a video (mpv)
helpList the available commands with explanations
install34Install to HDD/SSD from the live session (wipe / dual boot)

Everyday commands are a curated set shown up front (cd / ls / cat / man / nano / sudo / apt / help …). Commands used internally by the system are not deleted — that would break booting and apt — they are simply kept out of the default PATH.

ASTRO

Astro is 34OS's own user interface under development: a custom X11 window manager (34os-wm) written in C, which also provides the panel, the menu and the desktop in a single program. Its look is flat white line art on charcoal — the project's own wallpapers use the same style. In the current preview builds Astro ships alongside Fluxbox and can be tried by creating a ~/.34os-astro flag file. The release in which Astro becomes the standard session is v2.2 “TopNumber”.

STATUS

Under active development. The latest development build is v2.1e (preview, with Secure Boot support); the Latest release on GitHub Releases is v2.1d. The 2.1x series is being hardened on real hardware; the final, bug-free 2.1x build will be promoted as-is to the first branded release, v2.2 “TopNumber” (34OS Hachiroku-Rail TopNumber), scheduled for December 25, 2026.

About version letters: a trailing letter (b, c, d…) marks a fix release of the same version, not a new version — v2.1 → v2.1b → v2.1c → v2.1d → v2.1e are all revisions of v2.1. Only a change in the numbers is a new version.

PLEASE NOTE

34OS is Japanese-locale only (ja_JP.UTF-8). There is no English locale — by design, English support is left to volunteers. The interface, documentation and this project's day-to-day development are in Japanese. Bug reports and real-hardware test reports are welcome via GitHub Issues.
