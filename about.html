34OS

It's very hyper ultra super mega light-weight OS — バカ軽いOSを目指して作っている、個人専用の Linux ディストリビューション。名前の由来は「サンヨン = 3・4」。

34OSとは

34OS は、Puppy Linux 以下の軽さを目指しながら、コマンドの使い心地は Ubuntu と同じ（GNU coreutils + bash + apt）であることを狙った個人用 Linux ディストリビューション。使う人が使うものだけを表に出し、余計なものは裏に隠す方針。軽さの稼ぎ方はコマンドを削ることではなく、ロケール・ドキュメント・ファームウェアを削ぎ落として、ファイルシステムを SquashFS で圧縮すること。初代 Core i5 のノート PC（dynabook）など、古い実機でもテストしている。

  • 土台: Ubuntu 24.04 LTS（debootstrap 最小構成）
  • シェル: bash / パッケージ管理: apt
  • GUI: Xorg + Fluxbox（標準セッション）、Firefox（Mozilla公式 .deb — snap は使わない）、PCManFM、sakura ターミナル
  • 日本語入力: fcitx5 + Mozc 標準搭載
  • インストーラ: install34 でライブセッションから HDD/SSD へインストール — 全消し／デュアルブート、UEFI／BIOS 両対応
  • 起動メディア: Rufus（DD モード）または Ventoy。v2.1e 以降は Secure Boot に対応しているため、有効にしたまま起動できる（Microsoft 署名済み shim と署名済み GRUB を使用）。v2.1d 以前では Secure Boot の無効化が必要
  • ライブセッションのログイン: ユーザー user / パスワード live

独自コマンド

goguiGUI（標準は Fluxbox、~/.34os-astro がある場合は Astro）を起動する
gocliGUIを落としてCLIに戻る
browserブラウザを開く
img画像を表示する（feh）
play動画を再生する（mpv）
help使えるコマンドの一覧と説明を出す
install34ライブセッションから HDD/SSD へインストールする（全消し／デュアルブート）

日常コマンドは厳選して表に出す方針（cd / ls / cat / man / nano / history / sudo / apt / help …）。システム内部が使うコマンドは消さない（消すと起動や apt が壊れるため）。「見せない」のは PATH の制御で実現する。

ASTRO

Astro は 34OS の独自 UI。自作の X11 ウィンドウマネージャ 34os-wm（C 言語）が、パネル・メニュー・デスクトップまでを1つのプログラムで担う。見た目はチャコール地に白の線画で、プロジェクトの壁紙と同じ世界観。現在のプレビュー版では Fluxbox と同梱されており、~/.34os-astro フラグファイルを作ると試せる。Astro が標準セッションになるリリースが v2.2「TopNumber」。

ステータス

開発中。最新の開発版は v2.1e（プレビュー版。Secure Boot 対応。GitHub Releases の Latest）。標準セッションは Fluxbox で、独自 UI「Astro」は同梱して試験中。2.1x 系統は実機テストを繰り返して仕上げており、バグのなくなった最終の 2.1x ビルドをそのまま、初の製品名付きリリース v2.2「TopNumber」（34OS Hachiroku-Rail TopNumber）として 2026年12月25日 に正式リリースする予定。

バージョン表記について: 末尾のアルファベット（b, c, d…）は「同じバージョンの修正差分」を表す記号で、新しいバージョンではない。無印が初版（暗黙の a）で、修正のたびに b, c, d… と進む。たとえば v2.1 → v2.1b → v2.1c → v2.1d → v2.1e は、すべて v2.1 の修正差分である。数字が上がったときだけが新バージョンになる。
