34OS について ABOUT

34OS は、バカ軽い OS を目指して作っている個人専用の Linux ディストリビューション（になる予定のもの）です。

コンセプトは「Puppy Linux 以下の軽さ」と「コマンドの使い心地は Ubuntu と同じ」の両立。軽さはコマンドを削って稼ぐのではなく、ロケール・ドキュメント・ファームウェアを削ぎ落とし、ファイルシステムを SquashFS で圧縮して稼ぎます。使う人が使うものだけを表に出し、余計なものは裏に隠すのが方針です。

ロケールは日本語（ja_JP.UTF-8）のみ。英語は有志に任せることにしています。v1 は dynabook（初代 Core i5）での実機起動に成功済みです。

特徴 FEATURES

🪶

軽さ

約 500 MB

ISO サイズは約 500MB、目標は 300MB 台。ロケール・ドキュメント・ファームウェアを削ぎ落として軽くしています。

🐧

Ubuntu 互換

土台は Ubuntu 24.04 LTS の最小構成。GNU coreutils + bash + apt で、コマンドの使い心地は Ubuntu そのままです。

🇯🇵

日本語専用

ロケールは ja_JP.UTF-8 のみ。コンソールでも fbterm で日本語が表示でき、キーボードは jp106 配列。日本語入力は Mozc（fcitx5-mozc）を標準搭載予定です。

💿

インストーラ搭載

v1.2 から install34 を搭載。ライブ起動から HDD/SSD へ、全消し／デュアルブートの2モードでインストールできます。UEFI／BIOS 両対応。

⌨️

独自コマンド

gogui / gocli / browser / img / play / help など、日常コマンドを厳選して表に出します。内部コマンドは消さず、PATH の制御で「見せない」を実現しています。

📜

ライセンス

34OS 本体は WTFPL（コピーレフト条項付き）。改変版を配布する場合は、同じ条件で公開してください。©MximizR/Nekomimi
